# OPT-21 — retensi service worker lintas rilis

Build menghasilkan `aman-release.json`: identitas SHA256 konten, daftar aset final, SHA256 SRI tiap aset, entrypoint utama, dan dependensi kritis main/module-home/asset-dashboard/photo-lightbox. `source_sha` berasal dari `REACT_APP_RELEASE_SHA` valid 40 hex dan terpisah dari identitas konten. Editor dokumen berada pada dependensi dashboard, sehingga pembukaan pertama editor/lightbox tersedia setelah precache berhasil.

Cache rilis bernama `inventory-release-<id>`, metadata `inventory-release-meta-v1`. Install memverifikasi semua response, MIME JS/CSS/HTML dan SRI sebelum aktivasi; HTML yang mengacu rilis berbeda menolak install. Hashed aset publik cache-first tanpa revalidasi. Navigasi network-first; fallback hanya shell konsisten dengan chunk rilis worker. API, media autentikasi, websocket, mutasi, dan origin lain dilewati. Tulisan cache terikat `event.waitUntil`; respons jaringan sukses tetap sampai ketika quota cache/metadata habis. Reservasi metadata dilakukan sebelum put, sehingga crash bisa melebihkan hitungan tetapi tidak meninggalkan penambahan isi tanpa pencatatan.

Web Locks global menyerialkan metadata/mutasi antara worker aktif lama dan worker yang memasang rilis baru. Browser tanpa WorkerNavigator Web Locks menolak install baru, mempertahankan worker sebelumnya, dan menampilkan petunjuk memperbarui browser; aplikasi daring tetap tersedia. Tidak ada pemaksaan reload atau penghapusan IDB/draf.

Tab melaporkan bundle yang sedang dijalankan ketika controller berubah, kembali terlihat, dan heartbeat. Rilis aktif/pin dipertahankan; grace 24 jam melindungi pendahulu dan rilis baru. Maksimal empat catatan rilis, 500 aset/rilis, 128 pin klien, dan 64 MiB body tersimpan. Bila seluruh anggaran dilindungi, install berikut ditolak dengan petunjuk menutup tab lama setelah menyimpan perubahan. Metadata/isi rilis yang tidak lagi dilindungi dipangkas pada install/activate/pesan heartbeat/status. Cache v4 dikenal, awal migrasinya dicatat sebelum fetch sehingga retry gagal tidak mengulang grace, dan diberi satu kali grace di luar anggaran baru; cache aplikasi lain tidak dihapus. Pemangkasan membutuhkan event berikutnya, bukan timer yang diasumsikan selalu hidup.

Review independen menemukan dua celah, keduanya sudah ditutup dan diregresikan: fallback HTML200 pada URL JS serta old-active/new-install lost update. Suite worker-VM menguji penundaan tepat sebelum metadata old worker ditulis, install baru harus menunggu global lock. Suite juga menguji MIME, dua tab/dua rilis, grace/pin cleanup, budget penolakan, update checker dan quota. Paket terfokus tujuh suite / 39 uji lulus, termasuk sidebar responsif dan batas PDF; delta migrasi/cache/sidebar sesudahnya tiga suite / 17 uji lulus. Regresi migrasi mencakup cache v4 70 MiB, timestamp retry gagal yang tetap, serta pembersihan setelah grace. Delta hard-crash dan reservasi byte tiga suite / 22 uji lulus (termasuk put HTML lebih pendek yang sengaja ditahan sebelum mengganti body lama): kandidat cache yang sudah tersimpan sebelum metadata tidak diabaikan; retry gagal membersihkan kandidat tanpa record otoritatif; metadata hilang mengadopsi incumbent ke grace dan mempertahankan cache anggota yang masih dipin. Pembersihan hanya menyentuh namespace rilis 16-hex sendiri, menjaga cache aplikasi lain.

Lifecycle Chromium native, fixture HTTP lokal sintetis, 7,37 detik: dua tab/dua rilis; editor/lightbox rilis lama belum pernah dibuka berjalan setelah server memutus jaringan; reload dingin rilis baru berhasil; chunk404, koneksi putus, dan JS200 dengan byte salah (native SHA256 SRI) saat install mempertahankan worker valid; `Storage.overrideQuotaForOrigin=1` membuktikan respons jaringan lazy chunk sukses tanpa entry cache baru; draf input dan antrean IndexedDB tetap utuh. Fixture ini menguji template worker nyata dan browser CacheStorage/Web Locks; tidak menggantikan browser smoke aplikasi lengkap atau observasi produksi.

Server wajib tetap melayani hash chunk lama yang belum pernah dicache selama grace. Integrasi retensi static 24 jam/fail-closed budget milik OPT-08/25; worker tidak mengiklankan retained old chunks sebagai manifest rilis baru. Full production build harus menguji sumber final webpack untuk SRI dan byte deploy. Bukti lifecycle: [lifecycle-chromium.json](lifecycle-chromium.json).
